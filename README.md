# 🛡️AttackLens

AttackLens è uno strumento di security assessment automatizzato progettato per analizzare server, siti web e servizi esposti, individuare potenziali vulnerabilità e generare un report dettagliato dei risultati.

L'obiettivo è semplificare le attività di security testing, fornendo una panoramica centralizzata dello stato di sicurezza di un target autorizzato.

**Provalo subito su https://rosscoding.com/AttackLens.php**
